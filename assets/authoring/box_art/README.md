# Box-art source material

This directory retains original artwork, alternate covers, posters, screenshots,
bottom flaps, combined scans and rejected AI drafts. It is excluded by the
distribution asset collector. Runtime faces live in `assets/boxes`.

After the owner-selected mission-wrap increment, the archive contains 104 images: 31 selected original panel sources, six deterministic mission panel composites and four owner-authorized generated-background composites (Abyss front and three Shareware faces) feed 57 runtime faces across 19 titles. 41 other original/reference/preparation images and 22 generated donor/composite/rejected trials remain source-only. Original source bytes remain unchanged. Runtime derivatives use reviewed panel extraction and proportional fitting, including the separate back and spine extracted from intact `quaked/back-side.png`.

All spines are 340×2000. Front/back dimensions may differ; complete artwork and original element proportions take priority. Malice/Quoth use complete original panels; their three AI layout trials remain rejected. The Abyss side extension is a separate explicit owner authorization: its protected 646×975 center retains original pixels; only new wings and reviewed background-only joins use generated pixels. Four older spine inputs have only blank authoring margins removed around complete full-height printed strips. The owner-supplied Hexen II wrap now provides its full back panel. See [the repair record](../../../docs/box-art-repairs-2026-10-20.md).
