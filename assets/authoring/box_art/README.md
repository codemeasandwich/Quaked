# Box-art source material

This directory retains original artwork, alternate covers, posters, screenshots,
bottom flaps, combined scans and rejected AI drafts. It is excluded by the
distribution asset collector. Runtime faces live in `assets/boxes`.

After the Shareware owner-feedback alignment, the 20 October archive contains 94 images: 37 selected original sources plus four owner-authorized background composites (Abyss front and three Shareware faces) feed 57 runtime faces across 19 titles. 31 other original/reference/preparation images and 22 generated donor/composite/rejected trials remain source-only. Original source bytes remain unchanged. Runtime derivatives use reviewed panel extraction and proportional fitting, including the separate back and spine extracted from intact `quaked/back-side.png`.

All spines are 340×2000. Front/back dimensions may differ; complete artwork and original element proportions take priority. Malice/Quoth use complete original panels; their three AI layout trials remain rejected. The Abyss side extension is a separate explicit owner authorization: its protected 646×975 center retains original pixels; only new wings and reviewed background-only joins use generated pixels. Four older spine inputs have only blank authoring margins removed around complete full-height printed strips. The owner-supplied Hexen II wrap now provides its full back panel. See [the repair record](../../../docs/box-art-repairs-2026-10-20.md).

`q30a1024/screenshots.png` remains a screenshot collage rather than a cover.
`mg1/front-previous.jpg` and superseded retail images preserve former defaults.
The X-Men combined wrap is retained; its three panels exactly match the selected
separate front/back/spine sources. Other unused originals are documented alternates,
posters, flaps, jewel-case or disc photographs, rather than omitted default faces.

The historical [19 October move plan](../../../docs/evidence/box-art-consolidation-2026-10-19/move-plan.json)
records original paths, SHA-256 values and destinations for that batch. The current
[20 October derivation record](../../../docs/evidence/box-art-standardization-2026-10-20/derivation.json)
binds 82 retained inputs (including repair/alignment references and trials) to runtime panels and resolves superseded paths via
`historicalResolution`. The other 12 older archived images remain accounted for by the earlier move plan. Together these records cover
the entire source archive. See [current runtime provenance](../../boxes/SOURCES.md).

Multiple original paths with the same bytes share one canonical project file;
copying that file back restores the original content. Game directories, game data
and Quake's explicitly held launch poster are preserved. Retail Hexen II now includes the supplied back; other titles without supplied box faces retain placeholders.


The later [Shareware alignment increment](../../../docs/box-art-shareware-alignment-2026-10-20.md) retains the owner-feedback baseline, all original source panels, background donors, prior small-logo/blurred candidates and current composition masters under `shareware-alignment-2026-10-20`. Only new background/inspected background joins use generated pixels. Original printed front/back interiors and spine groups are restored deterministically; the id logo is uniformly enlarged from its original native crop under the owner's explicit refinement. The larger-logo transform supersedes the previous exact top-window proof and any claim that all old spine rows stay unchanged. The large QUAKE group and lower print/floppy group keep their source proportions and fixed reviewed placements.

Only the Abyss front and three Shareware background composites may be selected generated sources. No Malice/Quoth draft, trial wrap or unreviewed generated typography becomes a runtime role. The 82 declared input paths plus 12 older historical archive paths exhaustively account for all 94 images; counts above are derived from selected runtime paths and recorded source origins. Other54 runtime face hashes remain pinned to the owner-feedback baseline; archive retention does not mean those other boxes passed the stronger visible-edge acceptance for Shareware.
