# Box-art source material

These unchanged images are alternate covers, posters, screenshots, bottom flaps,
or combined scans. They are retained for authoring and provenance and are not
included by the distribution asset collector. Runtime faces live in `assets/boxes`.

No new image has been generated, cropped or extracted. In particular,
`quaked/back-side.png` remains the original combined back/spine image, and
`q30a1024/screenshots.png` remains a screenshot collage rather than a cover.
`mg1/front-previous.jpg` preserves the former bundled cover.

The [move plan](../../../docs/evidence/box-art-consolidation-2026-10-19/move-plan.json)
records original paths, exact SHA-256 values and canonical destinations. Multiple
original paths with the same bytes share one canonical project file; copying that
file back to any recorded source path restores the original image content.
Game directories, payloads and Quake's held launch poster are outside cleanup.
