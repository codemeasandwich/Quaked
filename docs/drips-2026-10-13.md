# Visible ambient drips

Effect 6 of T-3faa98e3. The engine uses the map's ordinary `ambience/drip1.wav` static-sound positions,
whatever game supplies them. It keeps playing the existing sound unchanged and shows falling drops
in Newer Game. Audio being muted or unavailable does not remove the visual cue. There is no map or
add-on allowlist, server entity, gameplay change, or new audio channel.

Options → Newer Game features → **Water drips** (`r_drips`, archived, default 1) controls this effect.
Turning it off retires its existing drops and splashes immediately without landing callbacks; the
other shared-layer effects are untouched. New Game and the Classic comparison hide the entire layer.

## Integration and bounds

`CL_ParseStaticSound` forwards the resolved sound name and copied position through the existing
`hooks.js` / `newer/install.js` boundary. The renderer resets the registry and motes on a new map,
registers the cvar, and updates the layer before the existing impact-ripple and wave frame functions.
The registry rejects nonfinite positions, holds at most 256 positions per sound and 1024 overall.

The inherited `r_motes.js` is one capped `THREE.Points` layer, not another weapon-particle system.
Its 512 slots are reserved as four independent 128-slot effect budgets (drips, light sparks, nail
impacts, lava embers). A full budget rejects new emission; no live particle is overwritten or borrowed
from another effect. Every particle first moves only for time it has actually existed. Pauses hold
positions; rewinds and mode resets clear both particles and emitter schedules. Per-particle point
size uses the actual scene viewport height and camera projection. The existing G-buffer shader hook
is retained; distance fog uses premultiplied colour so additive kinds attenuate without adding fog light.

Each source caches its vertical world-hull column. At most four new columns are evaluated per frame.
The source is rejected if inside solid or liquid, or if no floor is proven. Drops stay in the exact
traced XY column; a missing nearby ceiling uses the sound's own position. The existing solid hull
trace locates ceiling/floor. A bounded ordered traversal of those same point-hull leaves locates
liquid entry exactly: fixed eight-unit sampling missed thin pools. Unresolved/exhausted bounded queries
are distinguished from a proven dry column and suppress that drip. This is a read-only presentation
query and does not change server collision or physics. Moving brushes are outside this world-hull
query; this increment does not claim drop collision with lifts or moving doors.

A pool landing reuses `R_ImpactSegment` with an endpoint inside the proven liquid leaf, preserving its
water/portal handling. It adds a quiet ripple only when no existing impact event is
present. The drip is therefore oldest and later shots or bodies evict it before any existing impact;
an earlier shot is never displaced indirectly by admitting a drip. Lava consumes a drop. Dry landings produce a few short
splashes using the same layer and the same drip budget. Lens drops, venom, shotgun, lightning,
torches, existing impacts and Quake's original particle pools are unchanged.

## Verification

`tests/drips_test.js` drives the actual static-sound parser, point hull, emitter and particle public
interfaces: thin liquid entry/exit, fall column, pause, underwater-source exclusion, clock reset,
off-switch retirement, pool admission without live overwrite, independent owners, Classic exclusion,
registry bounds and reuse of the existing ripple detector. The adjacent menu/hook tests verify the
Options routing and architectural boundary. Actual GPU blending and independent review are separate
required checks before this increment is committed; their result must be recorded with its candidate.


Independent source/public verification passed 17/17 with no skips after correcting paused-off and
ripple admission. The additional probes force a physical drop landing and then saturate the shot
ripple pool, proving the earlier shot keeps normal capacity. `tests/drips_gpu_trial.html` passed seven
actual WebKit GPU checks with no errors: visible premultiplied drops, exact viewport scaling (9→18
pixels), projection response (18→10 pixels at the wider FOV), correct distance fog, additive light
attenuation, paused-off invisibility and Classic exclusion. These synthetic GPU fixtures do not claim
full-map/native acceptance; the commit gate, release and owner trial remain separate.
