# Batch 002 independent public verification

19 October 2026. Eight ordinary world materials: four Hexen II base identities
and four Portal of Praevus identities. This report qualifies authoring files,
not Hexen runtime integration or completion of the full texture campaign.

## Source and enhanced maps

`batch-002-public-tests.json` records eight independent synthetic public CLI
groups passing with stable tool/source hashes. They cover canonical 8× master
preparation, full-precision relief, measured registration on both axes, protected
existing files, invalid source/prompt/parameter/landmark rejection and absence of
per-tier generation controls.

`batch-002-public-actual-v1.json` independently checks the actual eight master
packages and **80 delivered WebP maps**. The native palette, indexed pixels,
RGBA identity, BSP map/slot and source PAK hashes match the retained inventory.
Each retained raw image supports at least 8× native dimensions and the original
aspect ratio. Canonical RGB and single float32 height masters replay exactly
through the existing finisher and material relief dependency.

Both Mid 4× and High 8× reproduce byte for byte from independent direct-master
reduction, normal and encoding oracles: lossy WebP quality 92, method 6. This
includes all diffuse, height and normal XYZ files. Half- and quarter-native BOX
comparisons, cyclic edge measurements and all three authored/decoded relief
angular comparisons were recomputed from the delivered lossy maps. These are
diagnostics; they do not by themselves establish visual acceptance.

## Preview binding

`batch-002-public-preview-v4.json` binds the batch manifest, original/prompt/raw
sources, master and tier receipts to the actual-map proof. Retained raw PNG
hashes also match the eight recorded generator-output files. This verifies
retained provenance, not an independent provider-side invocation count.

The public review CLI was rerun using its exact producer interpreter,
`/usr/bin/python3`, in an owned temporary directory. All **272 content and label
panels across 32 JPEGs** have pixel-identical decoded RGB. This includes native,
diffuse, 1:1 detail, repeats, both distance comparisons, height, normals and both
light directions. The HTML is byte-identical and all 32 image references resolve.

Strict JPEG-byte replay was overstrong and its HOLD receipts v1/v2 remain.
V3 additionally retained a too-narrow empty-padding bound. Full-file diagnostics
showed variance only in empty JPEG tail padding: the final 40×16 rectangle is
explicitly disjoint from all content and labels. V4 rejects any content/label
pixel difference, any variance outside that rectangle, or changed inputs. In
that replay 27 JPEGs differed only in this empty margin, with at most 402 changed
pixels and maximum channel difference 99. No material panel uses an error
tolerance. No preview or master was rewritten to obtain this result.

Temporary duplicate previews were removed. Inputs and the foreign staged diff
stayed unchanged; the three checked runtime binding files equal HEAD. There was
no browser, game, GPU or mesh-displacement test. Independent art review and owner
acceptance are separate from this technical result. The full world/model/sprite/
gfx scope remains open, as recorded in `batch-002-public-scope.md`.
