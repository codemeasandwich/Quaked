# Batch006 independent public verification

Both public verifiers passed on the completed batch with `/usr/bin/python3` (Pillow10.1.0, NumPy1.26.2, WebP1.3.2). These receipts qualify source, derivation and preview integrity. They do not grant artistic, owner, runtime, landing or release acceptance.

## Exact scope

Eight native bindings reference seven newly generated physical master packages and 70 physical enhanced map files. Portal `ttex021` reuses this same batch’s base `rtex029` master and ten maps after exact four-mip, palette, indexed-pixel, decoded-RGBA and own-Low equality proof. There are 80 map references, seven retained generation sources, one peer alias, and no previous-catalog master reuse. No duplicate `ttex021` generation or package was authored.

Each new source supports at least8× native dimensions at the original aspect ratio. Canonical RGB replay and a single full-precision float32 height replay matched exactly. All Mid4× and High8× diffuse, height and three normal-component WebPs matched independent direct-master Q92/method6 encodings byte for byte; none derives from a compressed tier. Native PAK/slot identity, immutable selection, retained prompt/source hashes and the peer’s four mip levels were checked.

Half- and quarter-native comparisons, cyclic edge statistics, decoded height error and three normal angular diagnostic paths were recomputed and matched their tier receipts. These measurements are diagnostics, not an automatic artistic or seamlessness pass. The separate reviewer must assess intended forms, repeated tiling and relief.
