Pin raw `4b431a5aece2e46314629b67fd1222967cf8cccf575629e5acdce0e250d1b074`, parent package `ad714db9bf3a153daae1ce0cbd3b5da25ddb2d571f438fe4a5b25641d7bea9cf`, its independent actual proof, native/prompt/tools, and proposed new package path. Describe each observed boundary-crossing fibre, source/destination patch rectangles, allowed change mask, intended continuation and protected native-scale landmarks. Measure a finite narrow repair corridor from the actual F1 views; do not borrow another texture's widths or choose one merely for a lower score. An independent reviewer must approve the exact recipe/masks before any implementation trial.

2. **Use explicit pixel transport with inspected cut paths, not alpha crossfade.** A small source-bound wrapper may replay the unchanged public ordinary master CLI exactly, then apply only the approved integer translations of donor patches from that same uncompressed master. Each donor patch crossing an output wrap must contain continuous source pixels on both sides of that wrap; it cannot itself sample through the raw/master's existing bad edge. Source scale/orientation remain fixed. Locate each patch's internal transition through reviewed actual interstices, keeping complete fibres together. Use binary ownership so each output RGB pixel comes from one source location, without blur, sharpening, procedural grain, mirrored fibres, synthesized material or a ghosted average of two strands. If a coherent donor and cut path cannot be found within the approved corridor, stop on HOLD rather than widen it silently or cut a visible fibre.

3. **Treat both axes and corners as one topology problem.** A half-tile roll can expose joins for inspection, but cannot be the fix. A simple donor roll still carries its own cut, and an independent X pass followed by Y can rebreak corners. The explicit recipe must assign the four corners and every overlapping side patch consistently on the torus, with actual continuous source neighborhoods at exposed wraps and no donor-cut line hidden inside another band. Keep the footprint outside the approved region byte-identical. This source-measured multi-patch binary compositor is the smallest missing mechanism proposed here; a generic synthesis engine or automatic unbounded seam search is unnecessary. If manual paths need assistance, a bounded minimum-error cut may only suggest paths inside independently approved interstice corridors; it cannot declare the resulting feature joins valid.
