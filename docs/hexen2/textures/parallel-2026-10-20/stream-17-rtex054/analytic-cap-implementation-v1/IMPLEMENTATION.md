The wrapper accepts a closed schema: `schemaVersion`, `policy`, `nativeIdentity`, `name`, `edition`, `nativeDimensions`, `sourceMasterPackage`, `sourceMasterPackageSha256`, `sourceVerification`, `originalSha256`, `authoringDiffuseSha256`, `authoredAtMasterDimensions`, `baselineProfile`, and `caps`. Additional annotations belong in the external review record, not as unknown recipe keys.

`caps` contains exactly `referenceSize`, fixed profile `paraboloid`, `plateHeight`, `capAmplitude`, `microAmplitude`, and `heads`. Each head contains only a unique bounded `label`, two-element `centre` and two-element `radii`, all finite non-Boolean numbers. Coordinates reference native pixel edges. The canonical 8× raster samples at `(i+.5)/8,(j+.5)/8`. Supports are disjoint interior ellipses; bounding boxes that overlap or touch are rejected conservatively. The tool bounds head count, total cap evaluations, image area, input bytes and metadata bytes. Radii need two canonical texels, and caps cannot contribute to the outermost sampled image border.

For each disjoint ellipse, the architecture is `plate + amplitude*max(0,1-rSquared)`. The cap term reaches zero at contact, eliminating the old binary height step. This is C0, not C1, continuity. The same verified float64 craft detail contributes only `(detail-.5)*(2*microAmplitude)`, and composition has one final float32 cast. The initial float32 NPY is checked against a separately replayed unquantized-detail cast; it is not consumed as prematurely quantized final authoring detail. Bounds must avoid clipping. There is deliberately no strict all-head-pixels-above-all-plate assertion: continuous contact makes their ranges meet. Bounded micro amplitude does not bound slopes or establish acceptable decoded ART.
