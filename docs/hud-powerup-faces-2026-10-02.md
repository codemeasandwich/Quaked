# Updated status-bar portraits and Quad + Pentagram selection

The owner updated `face2.webp`, `face_quad.webp` and `face_invul1.webp`. Their 96×96 WebP bytes are retained unchanged. The existing HUD index version is now `20261002`, giving loose-file image URLs a new cache key after reload.

`face_invul1` represents simultaneous **Quad Damage + Pentagram of Protection** (`IT_QUAD | IT_INVULNERABILITY`). The original PAK's `gfx.wad` already contains a native 24×24 `FACE_INVUL1` picture, but the port did not load or select it. `Sbar_Init` now loads it with the existing `Draw_PicFromWad` path. The native picture supplies both the name used by the optional high-resolution loader and the appropriate original fallback pixels.

In enhanced HUD mode, the status bar checks that both powerup bits are present before its existing powerup branches, including when invisibility is also present. It then draws the named `face_invul1` picture. `Draw_Pic` calls the existing `R_NewerHudCanvas`, which requests `newer/hud/face_invul1.webp?v=20261002`. The loaded picture remains drawn at the original 24×24 virtual dimensions. Pending, absent or failed optional artwork retains the native `FACE_INVUL1`; it does not copy another picture's high-resolution cache or require a new loader.

New Game, the classic demo half and the enhanced-HUD-off setting preserve their prior native face priority. Quad alone and the existing victory grin use `face_quad`; idle health 80–99 uses `face2`. Updated artwork changes presentation only: damage, powerup durations, inventory flags and health rules remain owned by the game.

Independent planning and public-interface review cover all eight combinations of Quad, invulnerability and invisibility across enhanced/classic/HUD-off views, actual indexed image requests, asynchronous loading/failure, native fallback, portrait dimensions, updated health/Quad/grin images and independent picture caches. The real ordinary Newer Game was also started through its normal menu and showed the updated face2 at health 90. Browser controls subsequently lost access to that view, so no claim of an actual picked-up Quad + Pentagram screenshot is made; that combined condition is verified through the public status-bar/loader tests.

Reload Newer Game with the status bar visible to see the artwork; acquire Quad and Pentagram together to see the combination. Source-dependent older weapon tests are separately blocked by removed donor archives, which this change does not restore. No public push or release is claimed.
