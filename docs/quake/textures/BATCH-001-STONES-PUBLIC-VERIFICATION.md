# Batch 001 stones: bounded public verification

`batch-001-stones-public-verification.json` records PASS for the actual retained `church1` and `maya1_9` opaque WORLD packages. This is source, arithmetic, codec and review provenance evidence. It does not accept the art, relief interpretation, repeats, runtime binding, owner trial, full campaign or release.

Reproduce from this worktree with `/usr/bin/python3 docs/quake/textures/batch-001-stones-public-verify.py`. The verifier replays production CLIs into its own temporary directory, removes that directory on completion, and writes only its JSON evidence under `docs/quake/textures`. It performs no generation, production map writes, registration, settings change or Git operation. Temporary replay paths in the JSON are recorded commands, not retained assets.

The actual native check reopens the PAK directories and the three bounded BSP occurrences listed in the earlier native proof: `church1` in `hip2m2` and `hip3m1`, and `maya1_9` in `r2m6`. It reconstructs palette-expanded RGBA, all four indexed mips, dimensions and texinfo flag sets, recomputes the full canonical identity, and compares the original PNG's decoded RGBA byte for byte. This also checks each descriptor's selected native identity. It does not claim a full independent enumeration of game archives.

Each unchanged native is 128×128. Both raw retained sources exceed 1024×1024 and preserve native aspect. Input original, raw and prompt bytes, prepare/finish/derive/normal tool hashes, master package hashes and tier receipt hashes are checked against current files. Historical generation count and returned-source attribution remain retained metadata; no generation transcript is authenticated by this run.

Two actual public `prepare_texture_master.py` invocations reproduce each full receipt and both `color.png` and float `height.npy` bytes exactly. Each master is 1024×1024; scalar relief is finite float32 in [0,1]. Both tiers bind the same RGB and scalar files. No Low output is authored, and original input bytes remain unchanged.

The independent oracles in `tests/hexen2_texture_tiers_test.py` reconstruct the actual periodic LANCZOS RGB reduction, float BOX scalar reduction, UV-scaled cyclic weighted derivatives, soft normal cap and normal encoding. An additional integer footprint mean checks the Mid BOX result within 8e-8 before quantization. Direct lossy WebP Q92/method 6 encoding then reproduces all 20 output files exactly: five roles per tier, Mid512 and High1024, for two materials. Each file is checked for decoded dimensions, receipt hash/size, and lossy VP8 rather than VP8L. Every normal set is distinguishable from normals derived from decoded compressed height. Height and angular compression divergence diagnostics, plus native/2 and native/4 BOX comparison measurements, are independently recomputed and matched to the receipts.

The public `build_texture_batch_review.py` CLI replays the actual descriptor into a new temporary output. Its complete output set, all eight JPEG sheets and HTML index, matches the retained `review-stones` byte for byte. The checked review tool reads the delivered decoded diffuse/height/XYZ files: it shows native enlargement, diffuse overview, 1:1 detail, aspect-preserving repeats, BOX comparisons of both inputs at both distances, normalized decoded XYZ and opposed lighting. This establishes current CLI provenance of the panels, not visual acceptance.

The JSON pins the verifier, independent oracle, descriptor, native proof, original/raw/prompt, both master and tier receipts, all maps and review outputs. Any later change to those bindings requires a fresh check. The independent art review remains authoritative for material, layout, hierarchy and tile-join findings even when this arithmetic evidence passes.
