## Reuse for a minimal correction

Use existing mechanisms only after the coordinator identifies the actual surface/native/UV relationship and demonstrates the defect:

- `update_level_sheets.py` already enforces source hashes, exact crop, orientation and native phase for the26 owner atlas names. Its default writes live assets and recrafts height; this inventory did not invoke it. A diffuse registration change must keep relief and the correct material semantics aligned.
- `finish_official_texture.py` provides photographic coarse-colour and measured landmark fitting. Preserve fine owner material and use only a reviewed gentle correction. Its successful resize does not prove adequate source resolution. Half/quarter comparison and owner-look judgment remain mandatory.
- `register_texture_boundary.py`/`register_texture_boundary_x.py` address compatible demonstrated intensity discontinuities. They do not relocate wrong joints, restore missing geometry or determine paired-material brush alignment. Their guarded package contracts must actually apply.
- `seam_fixes.json` records old edge operations, including a five-row bottom repair for `tech01_6`; preserve those facts rather than applying the tool globally. `fix_edges.py` crops/resizes artwork and is not the default minimal fix. `fix_offsets.py` and `align_frames.py` supply existing registration concepts, but their historical inputs/default in-place effects need care and are separate from native map UV offsets.

No new pipeline or production UI is needed for this source map. Root should validate the screenshot candidates, actual native identity and adjacent face transforms, then prepare one bounded candidate while preserving the current originals and source history. Exact visible working trials, independent edge/half/quarter/material review, landing and owner acceptance remain separate outcomes.
