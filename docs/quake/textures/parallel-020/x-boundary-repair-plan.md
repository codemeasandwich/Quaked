# X-boundary repair plan for the three held stone candidates

Independent planning review, 20 October 2026. This is a plan for a bounded same-source trial, not an implementation or an art PASS. The sealed [before-codec art review](root-independent-art-before-codec.json) remains unchanged: **city8_2, rock3_2 and wwall1_1 are all HOLD**. The accompanying [machine-readable plan](x-boundary-repair-plan.json) pins the actual masters, sources, tools and evidence inspected.

## Smallest justified reuse

The held cuts are at the original left/right boundary. `register_texture_boundary.py:periodic_y` already implements a zero-mean periodic-plus-smooth Poisson correction. An X trial should call that unchanged function on the transpose of the verified photographic RGB, then transpose the corrected image back. Transposition is an axis permutation only: no rotation, crop, landmark relocation, resampling, strip cloning, invented fracture, new noise, sharpening or perimeter band. Use one application with no tunable art strength or iterative search. Do not apply an additional Y correction.

The existing Y CLI is not a suitable executable wrapper: its `main()` hardcodes the Y operation, metadata and producer witness. Transposing its source package would break the original source-to-master replay and provenance. Monkeypatching its global function would give misleading producer/axis records. A narrow new X adapter is therefore justified, provisionally `tools/texture_sheets/register_texture_boundary_x.py`. It should reuse the existing `periodic_y`, photographic `finish`, `craft` and bounded input functions, and reproduce the existing guarded orchestration in its own small entry point. It must not copy another FFT implementation or edit the hash-pinned Y, prepare, finish, derive or craft tools. A future shared guard refactor is outside this increment.

The current photographic finisher already uses wrapped blur/resize for its coarse colour field. That prevents a new field frame but does not repair a non-tiling donor; its own documentation says so. Its `edge_anchor` option uses a one-native-texel band and only mean colours; it is unsuitable here. Strict projection would abandon the accepted photographic policy. Measured landmarks move forms and lack a demonstrated source-specific registration reason here. Motif and layered wrappers address different defects and should not be substituted.

## Applicability and stop rule

This Poisson operation changes intensity, not feature geometry. It does not promise identical first/last pixels: adjacent samples on a periodic texture need not be equal. It can reduce a tonal mismatch, but cannot align mismatched fracture endpoints, ledges or mineral shapes. The actual HOLDs include such detail cutoffs, so successful mathematical replay or lower edge MAE is insufficient. A single faithfully reproduced trial per texture is reasonable; confidence that it will clear all three art HOLDs is limited. If the straight cut, ghost band or implausible fine feature remains, retain HOLD. Do not iterate parameters, clone a strip, invent a joint, warp stones, generate another source or enlarge scope to obtain a PASS.

Although only the X forcing is applied, the smooth field is global. Y colours, corners and the contrast of legitimate joints can change. Preserving the native Y course joints and wwall's upper-course X joint is an explicit visual/physical gate, not a mathematical guarantee of this operator. No prior accepted binary should be replaced during the trial.

## Producer and proof contract

Before any implementation trial, bind a reviewed recipe to the exact native identity, name, edition, native dimensions, source master path/hash and sealed art HOLD hash. Keep a separate independent source/master-only proof with an explicit scope and one uniquely matching material row binding those same fields plus the original/raw/prompt, RGB and float-height hashes. A native-only proof lacks that master row; existing heterogeneous worker reports must not be silently treated as this schema. A source/master replay PASS may coexist with art HOLD and must state that limitation. Never fabricate an overall art PASS to satisfy a proof guard.

The adapter must reject before creating output when the recipe/proof binding, source role/path/hash, producer path/hash, original/raw dimensions, canonical filenames, generation count, RGB format, float32 shape/range or registration metadata differs. Require a single unrevised 8x photographic package, comparison divisor 2, `edgeAnchor` false, and no prior `periodicBoundary`, `masterRevision`, motif or layered authoring marker, even an empty marker. Require distinct resolved source paths; retain the existing bounded byte/pixel limits, nonempty bounded UTF-8 prompt and strict scalar-NPY validation (no pickle, trailing bytes, Fortran order, invalid type or nonfinite sample). Honour recorded landmarks during exact replay if supported; these three packages have none. Reconstruct the existing photographic RGB exactly and the old float-height NPY bytes exactly before correction, using the recorded profile. Merely trusting self-updated master hashes is insufficient.

At this planning observation all four recorded producer hashes in each source master still match current prepare/finish/derive/craft bytes. Recheck at action time. A later codec change or other producer drift must fail the guard; do not rewrite the historical receipt or ignore a mismatched tool. Pin both the imported unchanged Y operator's path/hash and the new adapter's path/hash, and verify that the imported callable comes from that expected module. Check watched recipe, proof, sources, masters and tools before output creation and again before sealing. Existing directories, ordinary files and dangling symlinks must be preserved and rejected as destinations. Write only a fresh root-assigned candidate directory.

Output is one new `color.png`, one newly authored full-precision float32 `height.npy` and `master.json`. Apply X correction to replayed RGB, return to original orientation, then call the unchanged physical-height author once on that final RGB with the same reviewed profile; do not patch the old NPY, derive height from compressed data or preserve old height while changing structural colour. The successor records the replaced package/RGB/height hashes, unchanged original/raw/prompt, `generationCount: 1`, no new generation, the X-only operation, operator and adapter hashes and actual environment. Keep historical `tools` witnesses truthful and separate from new producer witnesses; do not relabel old tool hashes as current. Recompute before/after edge and distance diagnostics in original X/Y orientation, not with transposed labels. Keep clipping/mean-change diagnostics without converting them into an art PASS. A successor remains unqualified until independent review.

## Public verification before actual authoring

Use synthetic public CLI fixtures in fresh temporary directories. The independent test must not import the new adapter or its `periodic_y` helper as the expected result. Reconstruct the X Poisson solution independently and verify the discrete-Laplacian residual and zero DC; assert exact corrected RGB and exact new scalar-NPY replay. Use non-square fixtures to expose an accidental Y operation or missing transpose-back. Cover a flat/no-op input, an X-only mismatch with distinct Y course structure, all corner joins, a clipping-prone saturated fixture and an intentional joint fixture. A fixture that improves boundary MAE while retaining an unmistakable misaligned geometric feature demonstrates the operation's limited qualification: it must not become an automatic acceptance claim.

Negative CLI checks must cover changed source/proof/recipe/producer bytes, redirected or missing producer, changed operator module, wrong native/material/master binding, an ART-only/native-only proof, malformed/trailing/nonfinite NPY, rehashed but non-replaying RGB/height, undersized/wrong-aspect/non-PNG raw, contradictory landmarks, bool/inexact generation metadata, unexpected input roles, prior correction markers, invalid profile/prompt, and existing or symlink destinations. Each rejection must be a normal nonzero exit, preserve all inputs and leave no candidate output. Record RED/GREEN public evidence for the new adapter and retained failures. No pre-existing fixture or maintained gate may be weakened.

## Actual bounded trial and independent acceptance

After the adapter and proof contract pass independent code/public review, process one source-bound candidate at a time in a fresh directory, preserving all old binaries and the sealed art HOLD. Examine corrected RGB before authoring further outputs. Record pre-clipping negative/overflow channel counts and masks, max/mean absolute correction, post-rounding means, broad palette changes and clipped locations. The operator's existing receipt exposes a combined clipped fraction; separate negative/overflow and spatial diagnostics can be calculated independently without changing its math. Reject lost detail, flat clipped patches, halos, new colour bands or noise-like material. Do not choose a permissive numerical clipping percentage to excuse visible damage.

Inspect relief before encoding: full float field, selected actual face/joint witnesses, edge continuation, both XYZ/opposed-light interpretations and especially wwall's legitimate upper X/Y joints. Any changed witness requires actual RGB-based reclassification, not relocating a point to obtain a passing number. Keep failed witnesses and images. Relief is newly authored from the corrected RGB, so earlier samples and replay are historical, not fresh qualification.

Only then derive Mid 4x and High 8x directly from the new shared RGB/float master through the separately qualified role-aware codec path. Colour remains Q92/method6; height/XYZ and qualified masks are lossless/method6. Verify intended quantization and exact decoded data values independently; codec-only migration of the old master does not repair this art failure. Rebuild all affected review panels against the actual new outputs, with pinned hashes.

Independent final art review repeats raw/master/material inspection, actual Mid/High at 1:1, both-input BOX native/2 and native/4, full 2x2 repeats, X/Y strips, rolled corners, height/XYZ and opposed lights. Compare old/new/native together. Require each held X cutoff to disappear, preserve all source-specific topology and physical face/joint relations, and retain recognizable natural material. Edge MAE is diagnostic only. Root may qualify individual textures; one passing candidate does not clear another. Runtime, catalogue integration, owner acceptance, landing, CI, cleanup and release remain separate gates. If the bounded X trial fails, retain HOLD and bring the concrete failed feature geometry back to root for a further authorized authoring decision.

Only these plan files were written in this planning task. No implementation, candidate, asset, master, tier, Git or Hexen mutation was performed. Root remains responsible for Bluey fallback reconciliation and any durable follow-up decision.
