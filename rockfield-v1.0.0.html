What each request needs

generateTile(surfaceConfig, tileX, tileY)

The seed, feature settings, resolution and surface coordinate frame belong to the whole surface. Only the tile coordinates change. Tiles can arrive in any order, including negative coordinates.

The demo uses two worker threads and a 96-page least-recently-used cache. A tile is generated once and sampled on the GPU thereafter. Drag the map to browse other coordinates; click to generate there.

What stays unchanged

The base-color texture, its repeat scale, the mesh and collisions are separate from the height field. Relief mode shifts texture lookup positions to simulate depth; Normals mode leaves those positions unchanged.

Height pages use 128 intervals, 129 shared-edge samples and two real gutter samples on each side by default. Level-zero filtering is shown here; production mip levels need world-consistent filtering and gutters at every level.

PNG export contains the selected 3 × 3 region with shared edges included only once. White means higher. The image is linear 16-bit data, not a color texture.
