The owner clarified that original pixels are an approximate depiction, not a
blueprint of rectangular blocks. Follow the original palette, material, scale,
recognisable features and intention, using natural photographic forms and
plausible fine detail. Existing owner-enhanced textures are the style reference.

instructions to keep going.

The current primary comparison reduces both images to half the native width

The secondary farther comparison reduces both to 16×16. These are visual
fidelity diagnostics, not demands for exact pixel equality. The owner's existing
enhancements legitimately differ in those comparisons. The former strict
projection experiments remain reproducible but are not the current art policy.

Do not add a whole-image bevel, border, vignette or edge shading. Preserve
intentional edge features and inspect self-repetition and actual cross-material
joins separately. A good colour score cannot repair wrong geometry or a seam.

## Current authoring method

1. Decode the actual native texture from the owned PAK, using engine palette
   conversion and its native texture identity. Preserve the source and hashes.
2. Generate photographic artwork with the built-in GPT image tool. Exact prompts
   and raw generated outputs are kept here; do not overwrite rejected attempts.
3. Use `tools/texture_sheets/finish_official_texture.py --method photographic`
   for measured registration and restrained smooth colour correction. It starts
   from the full photographic donor, not an enlarged native pixel grid. It
   reports half-native error, clipping and contour metrics without declaring
   automatic visual acceptance.
4. The optional `--edge-anchor` is only for a reviewed introduced border problem.
   It adjusts four boundary mean colours in a one-native-texel smooth band,
   preserving the interior. It is not a universal seamless-texture generator.
5. Run `encode_official_maps.py` on the reviewed 4x authoring master. Runtime
   diffuse and height images are lossy WebP quality 92; normals are derived
   from the decoded height and stored as three grayscale Q92 components.
   The existing loader recombines the components before normal generation.
   This avoids the measured chroma errors of a compressed RGB normal image.
6. Exercise real texture selection, normals, fallback and UV mapping. Normal
   bake publication must be coordinated with the concurrent enemy-skin lane.

CLI receipts sit beside candidate PNGs in
`newer/textures/candidates-2026-10-12`. They record the exact input/output/tool
hashes and any explicit landmark file. The finisher refuses overwrites and lossy
authoring-master output; the separate encoder produces lossy runtime images. Existing receipts are historical records; do not rewrite their old paths
to pretend they were created after a relocation.
