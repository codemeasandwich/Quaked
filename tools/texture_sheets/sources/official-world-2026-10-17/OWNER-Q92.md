# Retained owner material format successors

The owner requires every selected texture image map to use lossy WebP quality92 at exactly four times the original width and height. The earlier city5_3 and wizmet1_3 diffuse/height pairs meet the dimensions requirement but are lossless. These two artworks also serve the exact-native aliases metflor2_1 and mmetal1_3.

`normalize_owner_pair.py` makes four versioned copies through the existing pure `finish_runtime_skin.encoded` function. It verifies the independently planned predecessor hashes before encoding, preserves all source files, and never changes the index. It does not resize, recrop, adjust colour, repair seams, invent detail or recraft height. The selected authored height, material strength and cap remain the authority. The runtime already derives its normal map from the decoded scalar height; no new engine path or authored XYZ channel layout is needed for these pairs.

`owner-q92-first-tranche-v2.json` records the exact predecessors, source identities, unchanged allowlists, current and proposed descriptors, encoder and authoring code hashes, and encoded/decoded output hashes. The v1 script and receipt are retained. Review found that v1 checked the receipt destination after map writes and assumed its parent existed; v2 preflights that location first and supports a fresh scratch root. A fresh-root replay reproduced all four existing draft maps byte-for-byte. There are two owner format derivatives and four native bindings; these are not four newly generated photographic artworks. Original sources and earlier registration records remain immutable.

Installation must change only these four diffuse references, their four normal-file references and the catalogue version. All other recipe fields, including city strength2.4/cap2.1 and wizard strength1.2/cap1.1, remain unchanged. Original files remain available for strict atlas/phase/seam and historical-path checks. Any test successor overlay must be limited to these named, hash-bound transitions; unrelated owner expectations stay exact.

Qualification requires actual native PAK identities, public image upgrade and derived-normal paths, decoded-height inputs, cache refresh, Classic fallback, case/unknown rejection, native UV preservation and companion-pack reachability. Review the two decoded diffuses at full size and both native/replacement half32/quarter16 sizes, repeated edges, and lit relief. Encoder byte replay and actual VP8 chunks establish the requested format; a lossy codec alone cannot prove the quality setting. Gameplay through every level and owner appearance acceptance remain separate from this material trial.

The initial derivatives are uninstalled until those checks pass. Existing glass PNGs, other lossless maps, the twelve ledgered Q95 files, unresolved producer provenance and the R16 displacement/bake contract remain separate unfinished obligations. This four-map increment grants no exemption or release authority.
